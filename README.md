Object Detection Project

This project uses YOLOv8 to detect objects in video.
It works for both football matches and traffic scenes.

What it does
Detects people and vehicles
Tracks objects in real time
Displays results on video
How to run
pip install -r requirements.txt
python main.py
Notes

Video files, models, and logs are not included because they are too large.
